# 카카오 로그인 연동 트러블슈팅 가이드

카카오 소셜 로그인 연동 과정에서 발생한 주요 문제들과 해결 과정을 기록합니다.

## 1. 문제 현상 (Issue)
- **에러 메시지**: `Unable to exchange external code` 또는 `invalid_grant`
- **상세 내용**: 카카오 로그인 시도 시 인증 단계에서 실패하거나, 로그인이 성공하더라도 Supabase 유저 테이블에 정보가 적재되지 않고 로그인 화면으로 튕기는 현상 발생.

## 2. 원인 분석 (Analysis)
1. **이메일 수집 권한 부재**: 기본 카카오 앱 설정에서는 이메일 수집을 '필수 동의'로 설정할 수 없으며, Supabase는 이메일을 필수 데이터로 요구하는 경우가 많아 충돌 발생.
2. **비즈 앱 요건**: 이메일 수집 권한을 얻기 위해서는 앱을 '비즈 앱'으로 승격해야 함.
3. **Client Secret 불일치**: 카카오 디벨로퍼스에서 보안 강화를 위해 Client Secret을 활성화했으나, Supabase 설정에 반영되지 않아 `invalid_client` 에러 발생.

## 3. 해결 과정 (Solution)

### 단계 1: 비즈 앱 전환
- **조치**: 사업자 등록 번호를 입력하여 카카오 앱을 **비즈 앱**으로 전환.
- **이유**: 개인 개발자 앱은 이메일 수집 권한 신청이 제한적이기 때문.

### 단계 2: 개인정보 처리방침 등록 및 동의항목 설정
- **위치**: `앱 설정 > 일반 > 개인정보 처리방침`
- **조치**: 서비스의 개인정보 처리방침 URL을 등록.
- **결과**: `사용자 동의항목` 메뉴에서 **카카오계정(이메일)** 항목을 `선택 동의 [수집]`으로 설정 가능해짐.

### 단계 3: Client Secret 설정 (핵심)
- **위치**: `앱 설정 > 앱 > 플랫폼 키 > REST API 키 상자 > [클라이언트 시크릿]`
- **조치**: '카카오 로그인'용 Client Secret 코드를 생성하고 활성화(`ON`).
- **Supabase 적용**: Supabase Dashboard의 `Authentication > Providers > Kakao` 설정에서 해당 코드를 `Client Secret` 필드에 입력.

### 단계 4: 코드 수정 (Scope 조정)
- **파일**: `src/app/auth/login-form.tsx`
- **조치**: `account_email`, `profile_nickname`, `profile_image` 스코프를 명시적으로 요청하도록 수정.

## 4. 최종 결과
- 이메일, 닉네임, 프로필 사진 정보를 카카오로부터 정상적으로 받아옴.
- Supabase Auth에 유저가 등록되며 세션이 유지됨.

## 5. 향후 유지보수 팁
- **도메인 변경 시**: 실제 배포 시에는 카카오 디벨로퍼스 플랫폼 설정에서 `사이트 도메인`과 `Redirect URI`를 반드시 실서비스 도메인으로 업데이트해야 함.
- **Client Secret 노출 주의**: 이 키는 보안이 중요하므로 외부로 유출되지 않도록 주의.
